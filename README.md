# FateSteam

Этот воркспейс предназначен для работы с отзывами Steam по игре Tracery of Fate (app ID 1710670).

## Что здесь будет
- сбор отзывов за выбранный период;
- выделение важных тем, например баги, производительность, геймплей;
- формирование краткого отчёта по общему впечатлению пользователей.

## Структура
- `src/fetch_reviews.py` — загрузка отзывов из Steam API.
- `src/analyze_reviews.py` — анализ отзывов и формирование отчёта.
- `data/` — сырые и обработанные результаты.

## Быстрый старт
1. Установите зависимости:
   `pip install -r requirements.txt`
2. Скачайте отзывы:
   `python src/fetch_reviews.py --app-id 1710670 --start-date 2024-01-01 --end-date 2024-12-31`
3. Сгенерируйте отчёт:
   `python src/analyze_reviews.py --input data/raw_reviews_2024-01-01_2024-12-31.json`

## Примечание
Скрипты сделаны как стартовая основа для дальнейшей доработки: фильтрации по периоду, группировки по темам и улучшения качества отчёта.
